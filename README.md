# 华羽官网

华羽羽毛球品牌首页，包含中英双语内容、团队介绍、装备展示、成人训练、明日之星和球场影像。

当前目录只保留首页运行所需的源码、正式素材和静态回退资源。预约系统、后台、API、数据库配置、历史审查文件和演示小样均已移除。

## 本地运行

完整三维动效需要通过本地 HTTP 服务打开：

```bash
python3 -m http.server 4175 --bind 127.0.0.1 --directory "."
```

然后访问 `http://127.0.0.1:4175/`。

直接打开 `index.html` 时，页面会自动切换到静态浏览，保留首页内容和本地图片。完整三维开场、装备旋转和影像环绕使用 HTTP 入口。

## 主要文件

- `index.html` 是首页入口
- `main.js` 负责语言切换、训练选择、咨询内容和菜单交互
- `motion/` 包含三维场景、资源加载器、优化资源和 Three.js
- `assets/` 包含品牌图片、人物原帧和装备素材
- `data/team-credentials.json` 包含团队资料
- `_headers` 提供静态部署所需的响应头

## 发布

这是一个无需构建步骤的静态站点。将本目录作为静态站点根目录发布即可。页面的影片入口指向华羽官方发布页，页面不收集或提交个人资料。
